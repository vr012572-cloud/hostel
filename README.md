# GPG Hostel – Full Stack Website

Created by **Vaibhav Rathod**.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   ```bash
   npm install
   ```
4. Then:
   ```bash
   npm start
   ```
5. Open:
   `http://localhost:5000`

## Project structure

- `server.js` – Express backend + API
- `public/index.html` – website structure
- `public/style.css` – responsive 3D-style design
- `public/script.js` – API calls and contact form
- `package.json` – dependencies/scripts
